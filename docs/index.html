Running in three steps.

1

Install it

Download the ZIP, open chrome://extensions, turn on Developer mode, and load the folder unpacked.

2

Open X

Log in and click the x-unfollow icon. Press Start and it jumps to your following page for you.

3

Let it run

Watch it work or close the popup and walk away. Stop any time with one click.
